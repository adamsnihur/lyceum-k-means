Od Surowych Punktów do Optymalnych Skupień

Algorytm k-means (k-średnich) to fundamentalny algorytm uczenia nienadzorowanego, którego celem jest podział zbioru \(N\) obserwacji w przestrzeni \(d\)-wymiarowej na \(k\) rozłącznych skupień. Działa na zasadzie ciągłego przemieszczania tzw. centroidów (środków ciężkości), dążąc do minimalizacji sumy kwadratów odległości wewnątrz każdego klastra (WCSS).

Funkcja Kosztu
Min. WCSS (Inertia)
\(\sum_{j} \sum_{i} \|x_i - \mu_j\|^2\)

Moduł 1

Intuicja Geometryczna: Grawitacja Centroidów i Komórki Woronoja

Zanim przejdziemy do wzorów: wyobraź sobie przestrzeń jako pole przyciągania z \(k\) magnesami.

Wyobraźmy sobie zbiór punktów na płaszczyźnie, z których każdy reprezentuje klienta (np. [częstotliwość zakupów, wartość koszyka]). Nie znamy wcześniej żadnych etykiet klasowych. Naszym celem jest umieszczenie \(k\) centrów obsługi (centroidów) tak, aby każdy klient miał do swojego centrum jak najbliżej.

Dwa naprzemienne kroki geometrii:

  1. Podział terytorium (Komórki Woronoja): Każdy punkt na płaszczyźnie należy do tego centroidu, który jest do niego geometrycznie najbliższy. Granice między klastrami to proste symetralne odcinków łączących centroidy.
  2. Przesunięcie środka masy: Gdy każdy punkt zna już swoje terytorium, centroid przemieszcza się dokładnie w środek ciężkości (średnią arytmetyczną) wszystkich punktów należących do jego strefy.

Ponieważ średnia arytmetyczna z definicji minimalizuje sumę kwadratów odległości euklidesowych, każdy taki krok bezwzględnie zmniejsza lub pozostawia bez zmian całkowity błąd kwadratowy układu.

Fundamentalna Zasada Woronoja
Granice decyzyjne to zawsze hiperpowierzchnie liniowe:

Z tego faktu wynika kluczowa własność algorytmu k-means: skupienia zawsze tworzą wypukłe wielościany (politopy). K-means z założenia nie potrafi rozdzielić klastrów o kształcie koncentrycznych pierścieni czy półksiężyców bez wcześniejszej nieliniowej transformacji cech (np. Kernel k-means).

Moduł 2

Formalne Sformułowanie Matematyczne & Algorytm Lloyda

Ścisła dekompozycja optymalizacji nieliniowej i zerowanie gradientu.

1. Kryterium Optymalizacyjne (Funkcja Kosztu WCSS / Bezwładność)

Dla zadanego zbioru obserwacji \(X = \{x_1, \dots, x_N\} \subset \mathbb{R}^d\), algorytm poszukuje podziału na \(k\) rozłącznych podzbiorów \(S = \{S_1, \dots, S_k\}\) oraz wektorów centroidów \(\mu = \{\mu_1, \dots, \mu_k\}\), które minimalizują:

$$J(S, \mu) = \sum_{j=1}^{k} \sum_{x_i \in S_j} \|x_i - \mu_j\|^2$$

Gdzie \(\|x_i - \mu_j\|^2 = \sum_{m=1}^d (x_{im} - \mu_{jm})^2\) to kwadrat odległości euklidesowej w przestrzeni \(d\)-wymiarowej.

2. Krok Przypisania (Assignment Step)

Przy ustalonych położeniach centroidów \(\mu_j^{(t)}\), optymalny podział przestrzeni minimalizujący \(J\) polega na przypisaniu każdego punktu do najbliższego centroidu:

$$S_j^{(t)} = \left\{ x_i : \|x_i - \mu_j^{(t)}\|^2 \le \|x_i - \mu_l^{(t)}\|^2 \quad \forall 1 \le l \le k \right\}$$

W razie remisu punkt przypisywany jest do skupienia o niższym indeksie.

3. Krok Aktualizacji (Update Step)

Przy ustalonych zbiorach \(S_j^{(t)}\), szukamy nowego \(\mu_j\), który minimalizuje wewnątrzklastrową sumę kwadratów:

$$\nabla_{\mu_j} \sum_{x_i \in S_j} \|x_i - \mu_j\|^2 = -2 \sum_{x_i \in S_j} (x_i - \mu_j) = 0$$

Rozwiązując to równanie względem \(\mu_j\), otrzymujemy średnią arytmetyczną:

$$\mu_j^{(t+1)} = \frac{1}{|S_j^{(t)}|} \sum_{x_i \in S_j^{(t)}} x_i$$
Inicjalizacja Centroidów: Dlaczego k-means++? Arthur & Vassilvitskii (2007)

Standardowa losowa inicjalizacja łatwo umieszcza dwa centroidy w tym samym naturalnym klastrze, prowadząc do zbieżności w płytkim minimum lokalnym. k-means++ rozwiązuje ten problem probabilistycznie:

Krok 1: Pierwszy centroid \(\mu_1\) wybierany jest jednostajnie losowo spośród wszystkich punktów danych.
Krok 2: Dla każdego punktu \(x_i\) obliczamy najmniejszą odległość \(D(x_i)\) do już istniejących centroidów: \(\min_j \|x_i - \mu_j\|\).
Krok 3: Kolejny centroid wybierany jest z prawdopodobieństwem: $$P(x_i) = \frac{D(x_i)^2}{\sum_{m} D(x_m)^2}$$
Gwarancja teoretyczna: Oczekiwana wartość funkcji kosztu \(\mathbb{E}[J] \le 8(\ln k + 2) J_{\text{opt}}\), co eliminuje katastrofalne konfiguracje początkowe.

Moduł 4

Wybór Optymalnego k: Metoda Łokcia & Analiza Sylwetki

Ponieważ WCSS zawsze maleje wraz ze wzrostem liczby skupień, potrzebujemy kryteriów kompromisu między złożonością a dopasowaniem.

Metoda Łokcia (Elbow Method)

Krzywa WCSS(k)

Dla każdego \(k \in \{1, \dots, 8\}\) liczymy minimalną wartość bezwładności \(WCSS(k)\). Szukamy punktu przegięcia, po przekroczeniu którego spadek wariancji jest znikomy.

Wskazówka analityczna: Wartość \(WCSS(k=N) = 0\), więc sam spadek błędu nie oznacza lepszego uogólnienia. Punkt łokcia to geometryczny optymalny kompromis.

Analiza Sylwetki (Silhouette Score)

Wskaźnik \(s(i) \in [-1, 1]\)

Mierzy, o ile punkt jest bliższy swojemu skupieniu niż sąsiedniemu: $$s(i) = \frac{b(i) - a(i)}{\max(a(i), b(i))}$$ Gdzie \(a(i)\) to średnia odległość do punktów w tym samym skupieniu, a \(b(i)\) to najmniejsza średnia odległość do obcego skupienia.

Interpretacja: Wartości \(> 0.5\) oznaczają wyraźną separację. Maksimum średniego Silhouette wskazuje bezwzględnie najbardziej naturalną liczbę grup.

Trzy Pułapki Praktyczne w Zastosowaniach B2B & Data Science:

⚠️ Brak Standaryzacji

K-means opiera się na odległości euklidesowej. Zmienna o skali \([0, 100\,000]\) (np. przychód) całkowicie zdominuje zmienną o skali \([1, 5]\) (np. ocena NPS). Zawsze stosuj StandardScaler (\(z = \frac{x-\mu}{\sigma}\)).

⚠️ Niewypukłe Kształty

Z powodu liniowych granic Woronoja, k-means dzieli pierścienie i wstęgi na równe "tortowe" kawałki. Dla struktur gęstościowych stosuj DBSCAN lub HDBSCAN.

⚠️ Wrażliwość na Outliery

Pojedyncza gigantyczna wartość odstająca przesunie cały centroid o setki jednostek, rujnując spójność klastra. Przy obecności szumu rozważ k-medoids (PAM) operujący na medianach.

Moduł 6

Produkcyjna Implementacja w Pythonie

Wektorowy algorytm Lloyda w czystym NumPy (25 linijek) oraz referencyjny kod scikit-learn. 

import numpy as np
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

def vectorized_kmeans(X: np.ndarray, k: int, max_iter: int = 100, tol: float = 1e-4):
    """
    Wektorowa implementacja algorytmu Lloyda k-means w czystym NumPy.
    
    Parametry:
        X: np.ndarray o wymiarach (N, d) - zbiór danych
        k: int - liczba skupień
        max_iter: int - maksymalna liczba iteracji
        tol: float - próg zbieżności przesunięcia centroidów
    """
    N, d = X.shape
    # 1. Inicjalizacja k-means++
    centroids = np.empty((k, d))
    centroids[0] = X[np.random.choice(N)]
    for i in range(1, k):
        # Kwadrat odległości do najbliższego dotychczasowego centroidu
        dist_sq = np.min(np.sum((X[:, np.newaxis, :] - centroids[:i]) ** 2, axis=2), axis=1)
        probs = dist_sq / np.sum(dist_sq)
        centroids[i] = X[np.random.choice(N, p=probs)]
    
    for it in range(max_iter):
        # 2. Krok Przypisania (Assignment) z broadcastingu: (N, k)
        dists = np.sum((X[:, np.newaxis, :] - centroids[np.newaxis, :, :]) ** 2, axis=2)
        labels = np.argmin(dists, axis=1)
        
        # 3. Krok Aktualizacji (Update)
        new_centroids = np.array([X[labels == j].mean(axis=0) if np.sum(labels == j) > 0 
                                  else centroids[j] for j in range(k)])
        
        # 4. Sprawdzenie zbieżności
        shift = np.linalg.norm(new_centroids - centroids)
        centroids = new_centroids
        if shift < tol:
            break
            
    # Obliczenie końcowej bezwładności WCSS
    wcss = np.sum([np.sum((X[labels == j] - centroids[j]) ** 2) for j in range(k)])
    return centroids, labels, wcss
